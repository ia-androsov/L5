# Multiplicity of Limit Cycles Near Hyperbolic Polycycles of Codimension 5

<img width="803" alt="Screenshot 2024-05-31 at 00 45 03" src="https://github.com/ia-androsov/L5/assets/12882958/46c33f87-8249-4f73-8ba4-b9744bd23083">

This repository contains Wolfram Mathematica notebooks and data files related to the computation of the L5 polynomial.

- **`Poisson_L5.nb`**  
  Main Wolfram Mathematica notebook used for computing the L5 polynomial via the Poisson formula.

- **`DiscrL5.nb`**  
  Notebook dedicated to verifying the hypothesis concerning the discriminant.

- **`Res.wdx`**  
  Computation result stored in Wolfram Data Exchange format (`.wdx`) for reproducibility and further symbolic manipulation.

- **`respdf.nb`**  
  Mathematica notebook containing the final result.

- **`respdf.pdf`**  
  Exported PDF version of the final result.
